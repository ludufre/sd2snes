> **What is this?** A version of the [original sd2snes firmware](https://github.com/mrehkopf/sd2snes) by [@mrehkopf](https://github.com/mrehkopf) that keeps the firmware base and adds user-facing extras. Use this repo only for issues about **those additions** — for core firmware issues, use the original project.

## 👉 Full guides, downloads, tools and FAQ: **[sd2snes.ludufre.com](https://sd2snes.ludufre.com)**

Everything below is a quick overview. **The site has the step-by-step guides, screenshots and the web tools** — head there for anything beyond the basics.

## Get it running

1. Download the **full** `.zip` from [**Releases**](https://github.com/ludufre/sd2snes/releases).
2. Copy its contents to the **root of your SD card** (replace when asked).
3. **Fill your library:** with the SD card still in your computer, open the **[Web Manager](https://sd2snes.ludufre.com/manager/)** in your browser and connect the card — it scans your ROMs and downloads **box art, game-info cards (with animated video clips) and cheats** straight onto the card. Runs in the browser, nothing to install.
4. Put the card back and power on. The first boot offers a **tour of what's new** (one card per feature, each with its option right there) and asks you to set the clock: set it then, or later from Settings → Time; if you would rather not be asked at all, switch **Ask for clock on boot** off in Browser Options. Change the language anytime in the **Language** menu.

> [!NOTE]
> No games/ROMs are included — use your own legally obtained files.

> [!IMPORTANT]
> **Updating from 2.15 or older?** 2.15 moved saves, cheats, savestates, covers and game info into **two-letter folders** (`/sd2snes/saves/SU/Super Mario World.srm`), which is what makes a game open instantly on a card holding thousands of files, and **2.16 gives every console a folder of its own inside those** (`sgb`, `nes`, `sms`, `a26`, `sft`) — a sidecar is named from the ROM's stem, so before this a `Tetris (USA).nes` and a `Tetris (USA).sfc` shared one cover, one game-info card and one set of cheats. Nothing is deleted, but until the card is reorganised those files look like they are gone. The **[Web Manager](https://sd2snes.ludufre.com/manager/)** reads the firmware version off the card and organises it accordingly.

## Menu music

With **Random music** on (the default), every `.spc` in `/sd2snes/music/` is a candidate and the menu draws one each time it loads. Any file name works — the draw looks only at the `.spc` extension. The release ships these three; the same table is on the card as `/sd2snes/music/CREDITS.txt`. `/sd2snes/menu.spc` — the fallback when the folder is empty or Random music is off — is a copy of "28".

| File | Title | Author | Licence | Source |
|---|---|---|---|---|
| `un-tarde.spc` | un tarde | K. Jose | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) | [The Mod Archive #212763](https://modarchive.org/index.php?request=view_by_moduleid&query=212763) |
| `jungle-song.spc` | Jungle song | Beyond | Public domain | [The Mod Archive #181158](https://modarchive.org/index.php?request=view_by_moduleid&query=181158) |
| `28.spc` | 28 | Beyond | Public domain | [The Mod Archive #181427](https://modarchive.org/index.php?request=view_by_moduleid&query=181427) |

The tracks were converted from the authors' Impulse Tracker modules to SPC700 with [SNESMOD](https://github.com/mukunda-/snesmod). Changes: "un tarde" had one sparse channel folded into another to fit the eight voices of the S-DSP; "Jungle song" and "28" had their samples resampled to fit the 64 KB of audio RAM; all three got S-DSP echo.
